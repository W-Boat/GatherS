## 二、项目基线（交接必读）

- 技术栈：Miuix 0.9.3（ui/icons/preference）· Kotlin 2.4.10 · Compose Multiplatform 1.11.1（org.jetbrains.compose.* 坐标）· AGP 9.3.1 · Gradle 9.6.1 · minSdk 26 / compileSdk 37。
- 构建：push 到 main 触发 `Build APK` 工作流（JDK 21 + assembleDebug + 上传 artifact）；本地不构建。
- 源码布局：`app/src/main/kotlin/com/gathers/app/` 下 `data/`（数据层）、`ui/`（界面层）、`util/`（工具）。
- 功能现状：扫描与本地启发式打标、组合筛选、回收站（30 天）、智能规则开关、周/月报表与 Markdown 导出、多选批量清理。
- 已知限制：无真实 AI（OCR/视觉理解）；回收站还原仅 Android 10+；模糊度按需计算未批量；扫描为全量轮询无增量监听。

## 三、开发规划（方向性 Roadmap，按优先级）

### P0 稳定与体验（建议先做）
- 截图监听与增量更新：从"手动刷新/全量轮询"走向"新截图自动入库"，提升实时性。
- 缩略图与列表性能：大库滚动流畅性、内存占用优化。
- 回收站数据一致性：还原/清理的边界情况与异常恢复。

### P1 功能深化
- AI 能力接入（可插拔）：本地 OCR、图像场景分类、摘要生成；明确离线/在线策略与权限边界。
- 自定义智能规则：用户自建规则（来源/关键词/时效/动作）的界面与持久化。
- 批量模糊度检测与"低价值一键清理"。
- 闲时自动治理：定时后台任务（过期软清理、回收站到期清理）。

### P2 平台化与体验
- 多语言、无障碍支持。
- 报告增强：Excel 导出、更丰富的数据看板。
- 平板/桌面自适应布局。

### P3 工程质量
- 单元测试与 UI 测试落地。
- release 签名配置与上架准备。

## 四、开发目的选项（请选择方向）

- **A. 完善清理闭环**：增量监听 + 一键清理 + 后台自动治理（推荐，贴近产品核心）。
- **B. 接入真实 AI**：OCR/视觉摘要，需先确定 API/离线方案与隐私策略。
- **C. 打磨体验**：更多 Miuix 动效与组件、深色细节、平板适配。
- **D. 工程化收尾**：测试、签名、上架准备。

> 建议：以 A 为主线，穿插 C 的低成本优化；B 与 D 视资源另行排期。

## 五、交接约束（下个模型必须遵守）

1. 不在本地构建：改完提交推送，以 Actions 结果为准（改代码 → commit → push main → 查 run）。
2. 工具链红线：compileSdk≥37；AGP9 内置 Kotlin；org.jetbrains.compose.* 依赖坐标；gradlew 保持可执行位。
3. 改动后先在本地自查（import/签名/模板字符串），再推送，减少 CI 轮次。
4. 新增依赖前核对 miuix 兼容性与 Maven Central 可用性。
5. 提交信息用中文，说明改动意图；破坏性改动需在 PR/提交说明标注。
